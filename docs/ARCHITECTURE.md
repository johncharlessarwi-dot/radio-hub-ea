# Architecture

- **Web:** React + Vite + TypeScript, Swahili-first UI, later audio playback and PWA.
- **Crawler/API:** Node + Fastify, later SQLite, rate-limited public-source discovery and stream health checks.
- **Shared:** TypeScript station and health types.
- **Data:** metadata-first station seeds; no invented streams.

All live content remains with its respective broadcaster. No live audio/video is available until legitimate public URLs have been verified.
